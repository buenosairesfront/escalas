# U-MA Escalas

钢琴音阶实验室：选一个主音和 **61 种音阶**中的任意一种，应用会显示它的音和音程、双手指法、琶音、音阶内部的和弦，并让你把这些和弦串成一条声部进行流畅的和弦进行来播放。

**▶ 打开应用：** https://buenosairesfront.github.io/escalas/

无需安装。界面为西班牙语。

## 使用方法

页面是一张分为五个编号区块的技术单，顶部有**监视器**（一个点亮正在发声音符的键盘，以及音阶、音、级数和和弦的读数），底部有固定的**走带栏**。

### 01 · 音阶
- **主音：** 12 个音（黑键显示两种写法，例如 C♯ / D♭）。
- **类别：** 大调及其调式、旋律小调、和声小调、和声大调、五声音阶与蓝调、对称音阶、比波普和世界音阶。也可以在**搜索音阶**中输入。每张卡片用 12 个点显示音阶形状。
- **概览：** 大字名称、每个音按正确拼写并标出级数（1、♭3、♯4…）、音与音之间步距的彩色条（S 半音、T 全音、1½ 一个半全音、2T 两个全音）、**五线谱上的音阶**，以及在 12 音圆上显示形状的**时钟**。

### 02 · 键盘与指法
音阶显示在大键盘上，每个键有彩色圆点和指号（拇指、食指、中指、无名指、小指），可选右手、左手或双手。视图在**键盘**和**五线谱**间切换。下方是每个音及其手指的表格。大调和小调使用**传统**指法；其他音阶由应用**计算**一个（寻找别扭跨度和黑键拇指最少的指法），并注明为计算所得。

### 03 · 琶音
选择**级数**、**类型**（三和弦、七和弦或四度和弦）和**转位**。显示两个八度的琶音及其指法，同样是传统或计算所得。

### 04 · 和声化
把音阶**叠置**成三和弦或七和弦：每个级数一张卡片，含罗马数字、名称、性质（大、小、减、增…）、音程链、迷你键盘，以及在大调或小调时的功能（T 主、SD 下属、D 属）。每张卡片可按 **▶** 试听，按 **+ PROG** 加入进行。

### 05 · 和弦进行
最多 16 个和弦，每个一小节 4/4。载入预设（I–IV–V–I、ii–V–I、I–vi–IV–V、I–V–vi–IV、vi–IV–I–V、I–vi–ii–V、安达卢西亚进行、五度圈、全部级数）或自己搭建。各声部像钢琴家一样**移向最近的转位**，播放时大显示屏会显示当前和弦和小节。

### 走带（底部栏）
- **播放内容：** 音阶、琶音、和声化（音阶的和弦）或进行。
- **▶ / ■** 和 **loop**、速度，以及带节拍灯的节拍器。
- **手：** 双手、右手（MD）或左手（MI）。**方向：** ↑ 或 ↑↓。**八度：** 1 或 2。
- **音色：** Piano、EP（电钢琴）或 Pad。

页头可以切换音名（**Do Re Mi** 或 **C D E**）和浅色 / 深色主题。你的所有选择都会保存在浏览器中。

## 内部原理

一个没有依赖的 `index.html`。每种音阶以级数公式书写（`1 2 ♭3 4 5 6 ♭7`），因此每个音都会按所选主音得到正确的字母；和弦名称和罗马数字由实际音程推导。计算指法来自对每只手五根手指的动态规划搜索。绘图使用 `<canvas>` 和 SVG；三种音色用 Web Audio 实时合成（不用采样）。

## 本地运行

下载 `index.html` 直接打开，或用静态服务器：

```
python3 -m http.server 8000
```
