# U-MA Escalas

ピアノの音階ラボ。主音と **61 種類の音階** から 1 つを選ぶと、構成音と音程、両手の運指、分散和音、音階の中にある和音を表示し、それらの和音をなめらかなヴォイスリーディングで鳴る進行につなげられます。

**▶ アプリを開く：** https://buenosairesfront.github.io/escalas/

インストール不要。画面はスペイン語です。

## 使い方

ページは番号つき 5 セクションの技術シートで、上部に **モニター**（鳴っている音が光る鍵盤と、音階・音・度数・和音の表示）、下部に固定の **トランスポートバー** があります。

### 01 · 音階
- **主音：** 12 音（黒鍵は両方の表記を表示。例：ド♯ / レ♭）。
- **ファミリー：** 長音階と旋法、旋律的短音階、和声的短音階、和声的長音階、ペンタトニックとブルース、対称音階、ビバップ、世界の音階。**音階を検索** に入力しても探せます。各カードには音階の形が 12 個の点で表示されます。
- **概要：** 大きな名前、度数（1、♭3、♯4…）つきで正しく表記された各音、音と音の間の色分けバー（S 半音、T 全音、1½ 1 音半、2T 2 全音）、**五線譜の音階**、12 音の円の上に形を描く **時計**。

### 02 · 鍵盤と運指
大きな鍵盤の各鍵に色の丸と指番号（親指、人差し指、中指、薬指、小指）を表示。右手・左手・両手を選べます。表示は **鍵盤** と **五線** を切り替え。下には各音と指の表。長音階と短音階は **伝統的** な運指、それ以外はアプリが **計算**（無理な広がりや黒鍵の親指が最も少ない運指を探索）し、その旨を表示します。

### 03 · 分散和音
**度数**、**種類**（三和音、7 の和音、4 度堆積）、**転回形** を選ぶと、2 オクターブの分散和音が運指つき（伝統的または計算）で表示されます。

### 04 · ハーモナイズ
音階を三和音または四和音に **積み重ね**、度数ごとのカードにローマ数字、和音名、性格（長・短・減・増…）、音程の連なり、ミニ鍵盤、そして長調・短調のときは機能（T トニック、SD サブドミナント、D ドミナント）を表示。各カードの **▶** で試聴、**+ PROG** で進行に追加。

### 05 · 進行
最大 16 和音、各 4/4 拍子 1 小節。プリセット（I–IV–V–I、ii–V–I、I–vi–IV–V、I–V–vi–IV、vi–IV–I–V、I–vi–ii–V、アンダルシア進行、5 度圏、全度数）を読み込むか自作します。各声部はピアニストのように **最も近い転回形へ移動** し、再生中は大きな表示に現在の和音と小節が出ます。

### トランスポート（下部バー）
- **鳴らすもの：** 音階、分散和音、ハーモナイズ（音階の和音）、進行。
- **▶ / ■** と **loop**、テンポ、拍ランプつきメトロノーム。
- **手：** 両手、右（MD）、左（MI）。**方向：** ↑ または ↑↓。**オクターブ：** 1 または 2。
- **音色：** Piano、EP（エレピ）、Pad。

ヘッダーで音名（**Do Re Mi** または **C D E**）とライト／ダークを切り替え。選択はすべてブラウザに保存されます。

## 中身

依存関係のない `index.html` ひとつ。各音階は度数の式（`1 2 ♭3 4 5 6 ♭7`）で書かれているので、選んだ主音に対して各音が正しい文字で表記されます。和音名とローマ数字は実際の音程から導きます。計算による運指は、両手の 5 本の指に対する動的計画法の探索です。描画は `<canvas>` と SVG、3 つの音色は Web Audio でリアルタイム合成（サンプル不使用）。

## ローカルで動かす

`index.html` をダウンロードして開くか、フォルダを配信します：

```
python3 -m http.server 8000
```
